Flow Audit · waits off the path and only reads the notes

Flow Audit is not in the order's path. It waits outside and only reads.

It reads the notes each system already kept. It builds each order's journey. It points to the problem, the proof and the cause.

It writes to no system.

Measured and assumed

Measured: the orders, the records and the links. They are counted in the files.

Assumed: the minutes per case. Someone declared them. They are not measured at any operator. They can be changed in the configuration.

Estimate with example assumptions: gross about 978 h. Net, each order once, 925.9 h.

How an audit is run

  1. Each system hands over an export file.
  2. A mapping translates that client's columns.
  3. One command reads, joins the records and writes the report.
  4. The report opens in the browser, offline.

Limits

It finds the problem. It does not fix it. Correcting the cause is the operator's work.

Hours are an estimate with example assumptions. They are not a measurement and not a promise.

It is an open technical demo. A PDF and the engine's other languages come later.
