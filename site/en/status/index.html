Project status

What is being built?

  • Done · version 0.4.5. A made-up operator with 5,000 test orders, a test server, an example report and the engine: it reads the export files, joins the records saying how sure each link is, and runs the five rules (R01 to R05) with their hours. It writes findings.json and report.html.
  • Now. The audit example shows the five problems the engine wrote, with measured orders and hours as an estimate.
  • Next. Use that same mapping on a real client's files, in a folder outside the repository. The published demo still reads the synthetic files.
  • Later. A PDF report, a web interface and the engine's languages.
