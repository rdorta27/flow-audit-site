Project status

What is being built, and what is real, simulated or missing today.

What is being built?

Two stages. The second does not start until the first works.

Stage 1 · First real report

Read orders, service orders and activations from the test server, detect problem R04 (duplicate orders) and produce a report with its cost and formula. The cost of R04 is USD 1,590: USD 1,350 of manual clean-up (90 minutes per duplicate, an example rate) plus USD 240 of duplicate activations, which the engine does measure because activations are linked to their service order.

Stage 2 · Ready for a client

Read the files a real client exports (CSV or JSON), using a configuration that translates their columns, and also detect R01, R02 and R05. This is the requirement for auditing real data.

Later

R03 and the orchestration system, a PDF report, a web interface and the engine languages.

Done · version 0.3.5

A made-up operator with 5,000 test orders. A server that delivers them the way a real system would. An example report. Three readers (orders, service orders and activations): they already read all 5,000 orders, 5,020 service orders and 5,400 activation attempts, every record carries its origin and they are joined, saying how sure each link is; rule R04 already finds the 20 duplicate orders and values them at USD 1,590.

Now

Fix the format of the findings (findings.json) so the report can read it.

Next

Show each problem's cost with its formula and produce the real report.

What it does not do yet. It does not read customer data. It only detects R04. It does not generate reports yet. The example figures come from made-up data.
