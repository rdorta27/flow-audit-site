Help

Frequently asked questions and a glossary of the words this site uses.

Questions

Is it useful when the systems are new and solid?

Less, but yes. If one system follows the order end to end, much of this is already visible in its monitoring. It still helps in three cases: configuration or process errors (a missing field, a timer that expires with nobody acting), migrations (audit the month before and the month after with the same rules) and the gaps between teams, which no system flags. It does not replace monitoring: it turns it into hours and money.

Can I use it now?

No. It is under construction. The analysis will come in the next versions.

Where will it run?

On the auditor's computer, from the command line. It will not need a server or a database.

Will customer data leave?

No. Data goes in, a folder with the report comes out. Nothing is sent to outside services.

Will it change the systems?

No. It only reads. It never creates, changes or deletes orders.

What license does it have?

Open source, MIT license. It is a technical demo under construction. There is no commercial offer.

Glossary

The words this page uses, in order of appearance.

Order
What a customer buys, for example “SkyHome 200”. The sales channel receives it.
Order line
Each product inside an order. An order can have several lines.
Service order
The technical instruction the order manager creates to activate a line. There should be one per line.
Work order
The task for a person or crew, for example installing the dish.
Activation attempt
Each time the activation system tries to switch the service on. It can work or fail.
Retry
Trying again an activation that failed. It should reuse the original service order, not create another.
Link (explicit, inferred, missing)
How a record is joined to its order. Explicit: it carries the number. Inferred: deduced from other data, with less certainty. Missing: it could not be joined and stays in view.
Evidence
The specific records that prove a problem.
Snapshot vs history
A snapshot is the current state of a record; history is everything that changed and when. Measuring waits needs the history.
Gap
Time in which an order has no event at all: nobody does anything.
Finding
A problem the audit found, with its evidence and its cost.
Loaded hour
One hour of work at its rate (for example USD 45), used to price manual work.
Revenue at risk
Money not yet collected or that could be lost because the service is not activated.
BSS and OSS
An operator's systems. BSS handles sales and billing. OSS handles the network and activation.
TM Forum (TMF)
An industry association that publishes common formats so these systems can exchange data.
Test server
Our own program that imitates a real system with made-up data. It always states that the data is simulated.
