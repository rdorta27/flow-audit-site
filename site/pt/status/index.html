O que está sendo construído?

  • Feito · versão 0.4.3. Uma operadora inventada com 5.000 pedidos de teste, um servidor de teste, um relatório de exemplo e o motor: lê os arquivos de exportação, une os registros dizendo quão seguro é cada vínculo e executa as cinco regras (R01 a R05) com as suas horas. Escreve findings.json e report.html.
  • Agora. Mostrar o relatório do próprio motor neste site.
  • Em seguida. Ler os arquivos que um cliente real exporta (CSV ou JSON), com uma configuração que traduz as colunas. É o requisito para auditar dados reais.
  • Mais adiante. R03 e o sistema de orquestração, relatório em PDF, uma interface web e os idiomas do motor.
